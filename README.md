# Nostalgiabox

Nostalgiabox είναι custom RetroArch-based Android emulator app (v1.0.1).

## Στόχος

- Απλό, προρυθμισμένο RetroArch build για Android.
- Μόνο επιλεγμένα cores.
- Εκκίνηση παιχνιδιών απευθείας από το Kodi μέσω Android intent.
- Υποστήριξη PS1, NES, SNES, Sega, Arcade, Atari και PSP.

## Cores

| Πλατφόρμα | Core |
|---|---|
| PlayStation 1 | PCSX-ReARMed |
| NES | FCEUmm |
| SNES | Snes9x |
| Sega Mega Drive / Genesis / Sega CD | Genesis Plus GX |
| Sega Master System / Game Gear | SMS Plus GX |
| Arcade | FinalBurn Neo |
| Atari 2600 | Stella |
| Atari 7800 | ProSystem |
| Atari Lynx | Handy |
| PSP | PPSSPP |

## Σημαντικό

Το PS1 BIOS δεν διανέμεται με την εφαρμογή. Για PS1 χρησιμοποιείται το PCSX-ReARMed με HLE BIOS, ώστε ο χρήστης να μην χρειάζεται να τοποθετήσει BIOS.
