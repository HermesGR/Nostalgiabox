# NostalgiBox build plan

## Version 1.0.1

- Package ID: `com.nostalgiabox.retro`
- App name: `NostalgiaBox`
- Theme: black + neon magenta/cyan
- Logo: NB monogram with CRT scanlines

## Cores

- pcsx_rearmed
- fceumm
- snes9x
- genesis_plus_gx
- smsplus
- fbneo
- stella
- prosystem
- handy
- ppsspp

## Build stages

1. Build vanilla RetroArch APK.
2. Apply Nostalgiabox branding and configuration.
3. Bundle or whitelist selected cores.
4. Add Kodi intent launch support.
5. Publish APK through GitHub Releases.
